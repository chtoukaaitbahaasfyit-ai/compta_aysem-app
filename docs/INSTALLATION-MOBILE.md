# Installation et utilisation mobile (préparation)

L'application est prévue comme PWA : après déploiement sur un hébergement HTTPS, ouvrir son URL dans Chrome Android, ouvrir le menu ⋮ puis choisir **Installer l'application** ou **Ajouter à l'écran d'accueil** selon la version de Chrome.

Le service worker et le manifeste fournissent le socle d'installation. Ils ne signifient pas que la synchronisation hors ligne des données comptables est déjà développée. Ne saisissez pas de vraies opérations financières dans cette version de préparation.

Pour la mise en production, effectuer d'abord les étapes du document `SECURITY-AND-DEPLOYMENT-STATUS.md`.
